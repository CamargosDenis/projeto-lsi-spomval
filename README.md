# Busca Semântica com LSI e SVD

Trabalho da disciplina **SPOMVAL - Vetores, Geometria Analítica e Álgebra Linear** (Sistemas de Informação - IFSP Campus São Paulo).

## O que é

Um programa simples em Python que compara a busca tradicional (TF-IDF) com a busca usando Indexação Semântica Latente (LSI) e Decomposição em Valores Singulares (SVD) em uma base de 15 frases.

## Arquivos (pasta `TrabalhoLSI`)

* `LSI.py`: código principal em Python (usa apenas `numpy` e bibliotecas padrão).
* `Relatório LSl.pdf`: relatório completo do trabalho com os testes feitos.
* `teste1.txt`: resultado gerado no teste com a busca "chef".
* `teste2.txt`: resultado gerado no teste com a busca "futebol".
